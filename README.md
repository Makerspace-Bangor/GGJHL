# GGJHL
The GGJ Helper League is a cooperative meta-game running alongside Global Game Jam, where you score points by helping others succeed.

How to play:
Ask a team or jammer if they need help.
 -If they say yes: assist to the best of your ability and earn a point for each person you meaningfully help. 
 -If the problem is outside your expertise: pass it into a shared help queue so someone else can jump in. 
 
 There’s no penalty for asking, no obligation to accept help, and no competition between teams. 
 Only between helpers and the problems that slow jams & jammers down. 
 
 At the end of the jam, the winner is simply the person who helped the most people. 



 
 Prizes & glory you will receive Global recognition as being helpful. 
 Your contributions and status will be preserved on github for all to see. 
 A title on a leader board & affiliated bragging rights. 
 A hand made trophy.
